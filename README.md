Whitebox.asia - Web & Infrastructure Solution
Whitebox.asia adalah platform website dan layanan digital profesional yang menyediakan solusi menyeluruh, mulai dari Web Development, Server Management, Digital Marketing, hingga Kreatif Design.

🚀 Fitur Utama
⚡ Modern & Cepat: Dibangun menggunakan Next.js 14+ dengan optimasi server-side rendering.

🌓 Tema Adaptif: Dilengkapi dengan dukungan Dark Mode & Light Mode otomatis.

✨ Animasi Interaktif: Integrasi animasi halus menggunakan Framer Motion.

💻 Integrasi DevOps & Cloud: Menampilkan teknologi infrastruktur seperti Docker dan Azure.

📱 Sepenuhnya Responsif: Desain mobile-friendly yang dioptimalkan untuk berbagai ukuran layar.

🛠️ Teknologi yang Digunakan
Framework: Next.js (React)

Styling: Tailwind CSS

Animasi: Framer Motion

Ikon: FontAwesome & Lucide React

Server & Deployment: Nginx Reverse Proxy, PM2, Ubuntu

📂 Struktur Layanan
Development & Server: Full Stack & Server Management.

Digital Marketing & SEO: Jasa Backlink SEO, Build PBN, Social Media Ads.

Kreatif Design: Desain Logo & Pembuatan CV ATS-Friendly.
